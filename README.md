# Temperature Converter

A simple web app that converts temperatures between **Celsius**, **Fahrenheit** and **Kelvin**.

**Live demo:** https://mohantyakankshya.github.io/Temperature_Converter/

## Features

- Convert between Celsius, Fahrenheit and Kelvin
- One-click **Clear** button to reset the fields
- Lightweight: plain HTML, CSS and JavaScript, no frameworks or build step

## Tech stack

- HTML5
- CSS3
- JavaScript (vanilla)

## Project structure

```
Temperature_Converter/
├── index.html   # page markup
├── style.css    # styling
└── script.js    # conversion logic
```

## Run locally

No installation is needed.

1. Clone the repository
   ```bash
   git clone https://github.com/akankshya-mohanty-dev/Temperature_Converter.git
   ```
2. Open `index.html` in your browser.
